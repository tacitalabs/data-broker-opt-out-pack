## Upstream source

The choice of which people-search sites to cover was informed by the
Big Ass Data Broker Opt-Out List (BADBOOL), which is licensed
CC BY-NC-SA 4.0:
https://github.com/yaelwrites/Big-Ass-Data-Broker-Opt-Out-List

Changes from that list: the entries here were restructured into
machine-readable files, and the opt-out steps, requirements, confirmation
signals, and verification rules were written from this project's own
automation and run notes and from the brokers' own pages. Each broker file
lists where its facts came from in `provenance`.

BADBOOL's authors do not endorse this pack.
